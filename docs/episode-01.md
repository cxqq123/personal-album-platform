## 上架四要件（缺一不可）

| # | 要件 | 落在哪个字段 |
| --- | --- | --- |
| ① | 画作作者与名称 | `artist` / `artist_years` / `title_zh` |
| ② | 图片直接来源 URL | `image_url`（直链）+ `source_page_url`（人可核验的作品页） |
| ③ | 页面授权标识（CC0 / PDM / 忠实摄影副本说明） | `license` + `license_marker` + `license_url` |
| ④ | 获取日期 | `accessed_date` |

## 署名政策（比 CC0 更严）

**即使 CC0 不要求署名，前台也一律标注作者与来源。**

原因：CC0 放弃的是著作权财产权，**署名权属于人身权，在中国大陆等法域不可转让、不可放弃**。平台主动署名，既符合法律，也符合这类内容应有的态度。

## 来源风险分级

| 级 | 来源 | 处理 |
| --- | --- | --- |
| 🟢 可直接用 | Rijksmuseum、AIC、Met、CMA、Getty（逐件确认） | 填 CC0 直链，标注 `CC0` |
| 🟡 需署名、部分受限 | 台北故宫（政府资料开放授权条款，**不是 CC0**） | 必须署名；确认在开放清单内 |
| 🔴 禁商用 | 大英博物馆、北京故宫（默认）、卢浮宫、乌菲齐、梵蒂冈、普拉多、学院美术馆 | 不得直接用；须换来源或取得授权 |
| ⚪ 聚合层 | Wikimedia Commons | **不是来源**，必须回溯到馆方页面；文件页须明确标注 PD-Art / CC0 |

### 中国部分的现实

10 位里，7 位的主要藏地在**北京故宫或大英博物馆**——都在 🔴 区。一期唯一可行的路径是：

> 使用 Commons 上明确标注 **PD-Art（忠实摄影副本）** 的文件，页面注明"忠实摄影副本"，并保留原始馆藏信息。

这条路径在美国司法实践中成立（Bridgeman 案），但在中国大陆对"精确翻拍是否构成摄影作品"仍有争议。**一期可接受的风险边界是：非商业展示 + 完整署名 + 明确标注副本性质。** 一旦涉及付费或广告，须重新评估。
